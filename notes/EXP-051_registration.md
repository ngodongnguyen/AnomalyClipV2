### EXP-051 — Position-debiased zoom: does removing the zoom-induced centre prior help peripheral lesions? (H040; one-seed training pilot)

- **Hypothesis / status:** H040 / PLANNED (drafted 2026-10-15 before any EXP-051 code ran on real data; the user must confirm the rule before the sweep; do not change it after seeing numbers). Authorised by EXP-050 (Part A SUPPORTED: the training zoom centralises MVTec anomalies, A1 -0.139, and couples large extent with central position, A2 -0.133; Part B Z-COUPLED: the frozen ECP PE response at z_pix 1.6 shrinks to 25-56% at z_pix -0.69, close to the no-zoom CTRL level).
- **H040:** if the zoom crop places the anomaly so that the position statistics of the training mixture match the native frames (no centralisation, no extra size-centre coupling), the ECP pixel prompt learns less of the centre prior; peripheral lesions gain per-image pixel AUROC at the deployed z_pix 1.6, central ones do not lose, and the PE response G falls toward the CTRL level.
- **Only change:** `dataset.py` `_sample_crop_box` gains a default-off placement option. `--zoom_place uniform` (default) is the original code path and draws exactly the same random stream (unit test against a verbatim copy of the pre-EXP-051 function; Part A parity 9,407 / 8,768 must still hold). `--zoom_place beta --zoom_beta a` draws the crop corner as `lo + round(Beta(a, a) * (hi - lo))` per axis over the SAME admissible range, so the crop is the same size, still contains the whole anomaly, and the extent label z is unchanged in distribution (unit-tested); a < 1 pushes the anomaly toward the crop edges. No padding (EXP-037), no lesion cut, no change to the zoom probability (0.5), target range (0.10-0.45), loss, conditioner or evaluation.
- **Step A, source-only choice of a (CPU, no model, no medical data):** EXP-050 Part A pipeline (MVTec `meta.json` test anomalies, seed 111, 15 epochs, p 0.5, image outer / epoch inner) for the uniform placement (must reproduce the EXP-040 counts, else STOP) and for each a in the grid fixed now: 0.7, 0.5, 0.35, 0.25, 0.15, 0.1, 0.05. **Selection rule:** the LARGEST a in the grid with A1 >= -0.02 and A2 >= -0.03 (point estimates; the mildest change that removes both the centralisation and the extra coupling relative to the native frames). If no a qualifies: STOP, no training under this registration (a different placement or PE-jitter training needs its own registration). The selection is written to `results/EXP-051/sweep/selection.json` and read by the training script; nobody types a.
- **Step B, training pilot:** checkpoint `matched_eb_s111` = matched ECP recipe (`run_ecp.sh train`, MVTec, `--extent_cond extent`, `zoom_aug_p 0.5`, 15 epochs, batch 8, lr 0.001, `--features_list 24 --image_size 518 --depth 9 --n_ctx 12 --t_n_ctx 4`, `ec_teacher_p 0.5`, seed 111) plus `--zoom_place beta --zoom_beta a`. Reference: EXP-012 matched ECP seed 111 (SHA-256 `7278af95...`). The only difference between the two arms is where the anomaly sits inside a zoom crop.
- **Evaluation (unchanged test.py):** fixed `z_img -0.69`, `z_pix 1.6`, sigma 4, `--export_pixel_metrics`: pooled pixel AUROC / AUPRO on ClinicDB, Kvasir, ColonDB, ISIC, Endo, TN3K; image AUROC / AP on HeadCT, BrainMRI, Br35H. Per-image pixel AUROC paired with the EXP-032 per-image table of the matched ECP; lesion offset c from the EXP-033 position tables; terciles = the ceil(n/3) largest / smallest c (EXP-034). Mechanism: `analyze_pe_shift.py` (EXP-048 protocol, unchanged) on `matched_eb_s111` at z_pix 1.6, peripheral tercile, ClinicDB / ColonDB / Endo, paired with the EXP-048 ECP CSVs.
- **PRE-REGISTERED PRIMARY RULE (one seed; triage, not a claim):** decision sets ClinicDB, ColonDB, Endo (the EXP-048 decision sets; ISIC has no position response, EXP-035). Per decision set, peripheral gain = mean per-image AUROC (EB - ECP) over the peripheral tercile with a paired image-bootstrap 95% CI (2000, seed 0); central gain likewise. **ADVANCE** if the peripheral gain is >= +0.010 with CI lower bound > 0 on >= 2/3 decision sets AND all guards hold: central gain >= -0.005 on every decision set; no pixel set with pooled PRO or pooled AUROC change <= -1.0 point; no image set with AUROC change <= -1.0 point. **FAIL** if the peripheral gain is < +0.003 on >= 2/3 decision sets OR pooled PRO change <= -1.0 on >= 3/6 pixel sets. Otherwise INCONCLUSIVE; any missing value INCOMPLETE. ADVANCE authorises only seeds 222/333 of EB (matched ECP seeds exist) under the same rule averaged over seeds, not a claim.
- **MECHANISM (required for any statement that the gain comes from removing the centre prior):** per decision set Q = G_EB / G_ECP with G = PE_REC - PE_RAND (EXP-048), paired over peripheral images; REDUCED if Q <= 0.70 and the CI lower bound of G_ECP - G_EB > 0; UNCHANGED if Q >= 0.90; INVALID if G_ECP <= 0 or fewer than 3 paired images; otherwise MIXED. MECHANISM SUPPORTED if REDUCED on >= 2/3 decision sets; NOT SUPPORTED if UNCHANGED on >= 2/3; otherwise MIXED. Report-only: CTRL G (EXP-049, about +0.04 to +0.06) as the backbone floor; Kvasir, TN3K, ISIC position numbers; per-set pooled deltas.
- **Reading limits (written before the run):** one seed (pooled seed sd about 0.6-1.2 points; per-image AUROC CIs do not include training-seed variance); the grid and both thresholds of the selection rule are fixed now, but the grid was chosen without knowing where MVTec lands; a Beta placement changes how much context surrounds the anomaly inside a crop as well as its position; the backbone's own centre bias (CTRL level) cannot be removed by prompt training; evaluation sets are development sets (D027); the fixed z values were chosen on them historically.
